# Evergreen-Ecosystem
An edutech startup, the Evergreen Ecosystem is a system of educational games which follow the principles: 
- Curiosity before answers
- Understanding before memorisation
- Non-addictive by design
- Accessible to everyone
- Support, never replace teachers
- Learning through exploration
- AI as a guide

If you want to have updates/know more about these principles, find us on instagram @projevergreenapp!
